# Suburbia Park

Community website for the Suburbia Park neighborhood in Huntington Beach, California.

## Adding events and notices

Open `assets/js/data.js`.  Copy an entry in `SP_EVENTS` (calendar) or `SP_POSTS` (bulletin board), change the details and save.  Remove entries marked `sample: true` once real ones are in.

Forms (add an event, post a notice, suggestion box) are sent by email through FormSubmit, so every submission is reviewed before it goes on the site.
